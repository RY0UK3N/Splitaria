Esta versão torna as atualizações do Splitaria mais simples e seguras diretamente pelo aplicativo.

## O que mudou

- **Atualização integrada:** o botão em Preferências agora baixa e inicia a nova versão sem abrir manualmente a página do GitHub.
- **Verificação de integridade:** o instalador baixado é conferido pelo SHA-256 publicado na release antes de ser executado.
- **Retomada confortável:** ao concluir a atualização, o instalador abre novamente o Splitaria.
- **Autoria:** a licença e os metadados agora identificam Marcos Luciano Tagliari Junior como titular do projeto.

## O que permanece igual

- As preferências do usuário são preservadas entre versões;
- Fotos e vídeos continuam sendo processados somente no computador;
- Os arquivos originais nunca são alterados;
- Nenhuma conta é necessária.

> O instalador ainda não possui certificado digital de uma autoridade certificadora. O Windows pode exibir um aviso ao abri-lo pela primeira vez.
