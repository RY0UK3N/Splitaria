Este é o primeiro lançamento do Splitaria, um organizador de fotos e vídeos para Windows criado para tornar mais simples a organização de arquivos pessoais por ano e mês.

O projeto nasceu da necessidade de organizar grandes coleções diretamente pelo Explorador de Arquivos, com uma experiência confortável, visual e cuidadosa com os arquivos originais.

## O que chegou nesta versão

- **Organização por data:** prioriza a data de captura das fotos e utiliza o nome do arquivo ou a data de modificação quando necessário.
- **Pastas por ano e mês:** organiza fotos e vídeos nos destinos escolhidos, com diferentes padrões de estrutura.
- **Múltiplas origens:** permite analisar várias pastas juntas, incluindo subpastas.
- **Revisão antes de copiar:** mostra os arquivos encontrados, permite selecionar cada item e ordenar as colunas.
- **Detecção de duplicados:** compara o conteúdo dos arquivos e avisa sobre repetições e conflitos no destino.
- **Pré-visualização:** exibe fotos e vídeos dentro do aplicativo, com visualização ampliada e controles de reprodução.
- **Temas claro e escuro:** permite escolher o tema ou acompanhar automaticamente o Windows.
- **Instalador para Windows:** inclui atalhos, desinstalador e todos os componentes necessários para executar o aplicativo.

## Princípios desde o início

- Organização clara antes de qualquer cópia;
- Preservação dos arquivos originais;
- Processamento local, sem enviar fotos ou vídeos para a internet;
- Nenhuma conta ou serviço online obrigatório;
- Interface simples e confortável para uso pessoal;
- Código aberto sob a licença MIT.

> O instalador ainda não possui certificado digital de uma autoridade certificadora. O Windows pode exibir um aviso ao abri-lo pela primeira vez.
